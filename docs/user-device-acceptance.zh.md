# Memex 跨页面和设备验收

本表列出[功能地图](user-feature-map.zh.md)中仍需跨进程、系统界面或外部服务验证的动作。每一行给出设备上的操作和通过条件。执行后记录平台、版本及实际结果。

## 共同样本

在一次性安装里创建账号 A 和 B。A 有两条同一天的记录，一条含独特原文、红蓝两张图片、标签和一条回复，另一条只有文字。B 用相同标题记录不同内容。为每条记录保留 ID、原文、图片顺序和原文件摘要。为日期筛选再各加一条范围外记录。对话使用不同的角色、会话和仅属于各自的短句。恢复备份和删除账号使用测试专用存储。验收记录应写明提交、平台版本、操作、实际结果，以及失败时的记录或任务 ID。

| 用户入口 | 操作与变化条件 | 可观察的通过条件 |
|---|---|---|
| 首次使用、升级 | 全新安装完成引导，强制退出重开；用旧版工作区重复 | 新安装进入首页，旧安装保留原账号、工作区、语言及已有记录 |
| 首页记录与列表 | 输入含换行的原文，选两张图发送，等处理完成；记下卡片 ID 后强制退出重开 | 首页只出现一条完成记录，进入详情读到原文，附件顺序、两张实际图片与输入一致 |
| 详情评论与提醒 | A 的第一条记录留言、回复；从活动中心进入同一条详情并返回，再重开 | 评论与回复在原线程，另一条记录无新增留言；已查看的提醒消失且重启后保持 |
| 时间线、筛选和刷新 | 筛标签，滚到下一页，打开目标并返回；等待更新时下拉刷新，再修改标签和删除 | 返回后的首个可见条目和过滤条件保持；同一 ID 只有一项，已删记录在列表与详情都无法重新打开 |
| 离线恢复与后台任务 | 断网发两条，删除第一条；强制退出，再联网重开；切换前后台两次 | 第一条不再出现，第二条及其结果均唯一；任务状态可见且最终离开等待态 |
| 录音与转写 | 分别拒绝、允许麦克风；录音后取消、结束、修改转写并发送；使转写中断一次 | 取消不产生记录，已有草稿能找回；成功的记录含修改后的文字和可播放的原录音 |
| 系统输入和导入 | 从分享面板发送文字与图片，从相机、相册、文件、剪贴板各进入一次；选择、取消、拒绝后重试 | 取消可返回原草稿；确认后内容齐全，在详情或导入目录重新打开；同名不同内容均可找回 |
| 图集和音频 | 列表滚过两条不同带图记录，来回滑图、双指缩放、退回；播放语音时离页并模拟系统中断 | 旧图不会覆盖当前图；放大和翻页都能操作；音频暂停与恢复状态和当前附件匹配 |
| 日历与回顾 | 从首页切换到周视图和日历；在月末、跨年、夏令时切换前后两个时刻各存一条，按本地日期打开 | 每条记录恰好出现在对应日，点击返回同一 ID 的详情；空日期不借用邻日记录 |
| 知识库搜索及预览 | 搜索独特关键词，点击命中，再改名、改内容、删除文件，等待自动索引后重开 | 搜索项指向正确路径和正文；新词可查，旧词消失，切到 B 看不到 A 的结果 |
| AI 整理和关联 | 发送带图的合成记录，让已配置模型生成卡片；打开标签、关联卡和附件；处理中一次断网再重试 | 卡片引用实际存在的原记录和附件，失败有提示，重试后只有一个完成结果 |
| 助手对话与澄清 | 引用附件，连续发送两条，取消其中一轮，再切会话重开；让提供商返回一次错误 | 草稿与历史可恢复，答复归属正确轮次；取消轮次不能在后台执行第二次操作 |
| 系统动作和权限 | 对测试用系统动作依次选择拒绝、允许、重复确认；系统设置撤权后重试 | 拒绝和撤权没有系统副作用；一次确认只生成一个可在系统中找到的对象 |
| 后台日志和恢复 | 启动有中间产物的任务，后台中断后重开；从任务面板查看失败并重试 | 同一任务的状态和错误可查，已完成产物不重复，下一项可以执行 |
| 知识库目录和导出 | 从系统选择文档导入，打开知识库目录、预览、关联原卡；导出后在文件 App 打开 | 路径、正文及媒体与样本匹配；失败和空目录有可返回的页面 |
| 洞察与模板 | 用合成记录生成洞察，打开关联卡，固定后重启；再尝试缺失模板 | 固定项仍存在且指向原记录；缺失模板有可读提示，其他洞察仍能打开 |
| 记忆与角色 | 在角色编辑页修改一条记忆、删除另一条并保存；重开编辑页，开始该角色的新会话 | 编辑页读回修改；新会话取得该角色更新后的上下文，另一角色的记忆保持原样 |
| 角色导入与私聊 | 从文件选择器导入角色卡和头像，处理同名冲突；切角色发言并检查主动消息、通知和历史 | 头像与角色匹配，旧角色配置可找回；各自会话只包含自己的消息与回复 |
| 备份与恢复 | 用系统文件选择器导入当前版和旧版测试备份；取消一次，确认一次，恢复后冷启动 | 取消后数据保持；恢复后最新记录、标签、评论和可打开的原附件一致 |
| 工作区与账号隔离 | 切换 A、B 和各自的存储目录，迁移或克隆后分别重启，搜索同一标题并打开通知 | 每个账号只看到自己的正文、附件、通知和搜索结果；原工作区仍可打开 |
| 锁屏和隐私 | 启用 PIN 和生物识别；后台超过宽限期、取消认证、输错 PIN，再输对；查看任务切换预览 | 认证成功前不能操作受保护页面，切换预览不泄露正文，成功后可回到记录 |
| 提供商和账号连接 | 设置默认模型和两个不同角色，测试连接；OAuth 返回、取消和过期后分别重新进入 | 选择可回读，角色互不串配置；取消可退出，失败的操作可重试，草稿仍在 |
| 地点、健康与系统授权 | 系统弹框分别允许、拒绝和撤权，再创建记录并查看地点或健康相关页面 | 允许时关联正确数据，拒绝时可继续记录，撤权后不会复用另一条记录的授权结果 |
| 外部存储 | 在支持的平台选择本机目录、iCloud 或 Android 文档树；导出后撤销目录授权 | 外部可打开导出文件；撤权后提示重新选择，旧文件仍可由持有人读取 |
| 外观、语言与无障碍 | 切为 RTL 语言、增大字号、重开后用系统辅助功能走记录和评论链路 | 主要按钮可达、文案不遮挡，语言变化不改记录 ID、原文、评论关联和日期 |
| 设置、诊断和版本更新 | 从设置搜索到目标子页，修改后重进；模拟更新取消、失败、成功升级 | 设置保持，错误可查；取消或失败仍可使用原版本和工作区，成功升级能回读旧数据 |
| 评论设置 | 关闭自动评论后发普通记录与显式提及角色的记录，打开后设置人数上限再发送 | 普通记录没有自动评论，显式提及按规则处理，自动参与数不超上限，手动留言始终可用 |
| 按范围重处理 | 选择包含一条记录的范围，分别选仅卡片和含后续任务；取消、执行、重试各一次 | 取消无变更；范围外记录不动，实际更新和所选范围一致，下游产物不重复 |
| 删除本地账号 | 选含普通文件与备份的测试目录；输入错误、取消、最后正确确认，强制退出重开 | 错名和取消保留数据；确认后进入初次设置，当前账号工作区及数据库消失，B、普通文件和外部备份完整 |
